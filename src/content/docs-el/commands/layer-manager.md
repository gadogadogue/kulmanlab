# LayerManager

Η εντολή `LayerManager` ανοίγει έναν πίνακα που παραθέτει όλα τα επίπεδα του σχεδίου, με τις ρυθμίσεις **Freeze** (πάγωμα), **Lock** (κλείδωμα), **Plot** (εκτύπωση), **Χρώμα**, **Πάχος γραμμής** και **Τύπος γραμμής** επεξεργάσιμες απευθείας στη γραμμή. Είναι το κεντρικό σημείο για την προσθήκη νέων επιπέδων και την προσαρμογή της συμπεριφοράς των υπαρχόντων — οι υπόλοιπες εντολές επιπέδων ([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/)) κάνουν η καθεμία ένα συγκεκριμένο πράγμα χωρίς να την ανοίγουν.

## Άνοιγμα του Layer Manager

- Πληκτρολογήστε `LayerManager` στο τερματικό, **ή**
- Κάντε κλικ στο κουμπί **Layer Manager** στο πάνελ επιπέδων.

Το παράθυρο διαλόγου ανοίγει ως αιωρούμενο πάνελ· δεν χρειάζεται να έχει επιλεγεί τίποτα εκ των προτέρων.

## Ο πίνακας επιπέδων

| Στήλη | Τι ελέγχει |
|-------|--------------|
| Name | Το όνομα του επιπέδου, εμφανίζεται μόνο για ανάγνωση στον πίνακα (ορίζεται μία φορά, κατά τη δημιουργία) |
| Freeze | Κρύβει τις οντότητες του επιπέδου και τις αποκλείει από την επιλογή μέχρι να ξεπαγώσει |
| Lock | Εμποδίζει την επεξεργασία οντοτήτων στο επίπεδο, χωρίς να τις κρύβει |
| Plot | Αν οι οντότητες του επιπέδου συμπεριλαμβάνονται κατά την εκτύπωση ή την εξαγωγή σε PDF |
| Color | Το χρώμα ACI του επιπέδου — κάντε κλικ στο δείγμα για να ανοίξετε τον επιλογέα χρώματος |
| Lineweight | Το πάχος γραμμής του επιπέδου — κάντε κλικ στο chip για να ανοίξετε τον επιλογέα πάχους |
| Linetype | Το μοτίβο γραμμών του επιπέδου — κάντε κλικ στο chip για να ανοίξετε τον επιλογέα τύπου γραμμής |

Η εναλλαγή Freeze, Lock ή Plot έχει άμεση ισχύ — δεν υπάρχει ξεχωριστό βήμα αποθήκευσης. Οι οντότητες που έχουν οριστεί σε **ByLayer** για χρώμα, πάχος γραμμής ή τύπο γραμμής (η προεπιλογή) υιοθετούν ό,τι ορίζετε εδώ· οι οντότητες με τη δική τους ρητή παράκαμψη δεν επηρεάζονται.

## Προσθήκη επιπέδου

1. Κάντε κλικ στο **+ Add Layer** στο κάτω μέρος του πίνακα.
2. Πληκτρολογήστε ένα όνομα και πατήστε **Enter** για επιβεβαίωση, ή **Escape** για ακύρωση.

Τα ονόματα επιπέδων μπορούν να περιέχουν γράμματα, αριθμούς, κενά και `_`, `-`, `$`. Ένα όνομα κενό, ήδη σε χρήση, ή που περιέχει οποιονδήποτε άλλο χαρακτήρα απορρίπτεται με ενσωματωμένο μήνυμα σφάλματος, και η γραμμή παραμένει ανοιχτή για νέα προσπάθεια.

Τα νέα επίπεδα ξεκινούν **ξεπαγωμένα, ξεκλείδωτα, εκτυπώσιμα**, με χρώμα 7 (λευκό/μαύρο), πάχος γραμμής Default και τύπο γραμμής Continuous — τις ίδιες προεπιλογές που το [Import](../import/) αναθέτει στο επίπεδο `0` σε ένα κενό σχέδιο.

## Τι δεν μπορείτε να κάνετε εδώ

Δεν υπάρχει κουμπί διαγραφής — τα επίπεδα δεν αφαιρούνται ποτέ μετά τη δημιουργία τους, μπορούν μόνο να παγώσουν ή να παραμείνουν αχρησιμοποίητα. Ο πίνακας επίσης δεν υποδεικνύει ποιο επίπεδο είναι το *τρέχον*· αυτό ορίζεται από το αναπτυσσόμενο μενού στο πάνελ επιπέδων ή με το [LayerMakeCurrent](../layer-make-current/), όχι από αυτό το παράθυρο διαλόγου.

## Αναφορά πληκτρολογίου

| Πλήκτρο | Ενέργεια |
|---------|----------|
| `Enter` | Επιβεβαίωση του ονόματος ενός νέου επιπέδου (κατά την προσθήκη) |
| `Escape` | Ακύρωση προσθήκης επιπέδου, ή κλείσιμο του παραθύρου διαλόγου |

## Σχετικές εντολές

| Εντολή | Τι κάνει |
|--------|----------|
| [LayerMakeCurrent](../layer-make-current/) | Ορίζει ως τρέχον επίπεδο το επίπεδο αντικειμένου που κλικαρίστηκε |
| [LayerMatch](../layer-match/) | Αναθέτει εκ νέου επιλεγμένα αντικείμενα ώστε να ταιριάζουν με το επίπεδο ενός αντικειμένου πηγής |
| [LayerIsolate](../layer-isolate/) | Παγώνει όλα τα επίπεδα εκτός από αυτά των επιλεγμένων αντικειμένων |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | Ξεπαγώνει όλα τα επίπεδα με ένα βήμα |
