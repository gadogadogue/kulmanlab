# Trim

Η εντολή `trim` αφαιρεί το τμήμα μιας [Line](../line/), [Arc](../arc/), [Circle](../circle/), [Ellipse](../ellipse/), [Polyline](../polyline/) ή Spline που βρίσκεται μεταξύ δύο παρακείμενων σημείων τομής, χωρίζοντας την οντότητα σε ένα ή περισσότερα εναπομείναντα τμήματα. Το τμήμα που θα κοπεί καθορίζεται από τη θέση του κέρσορα — τοποθετήστε τον κέρσορα πάνω από το τμήμα που θέλετε να αφαιρεθεί και κάντε κλικ για κόψιμο.

## Κόψιμο μιας οντότητας

1. Πληκτρολογήστε `trim` στο τερματικό ή κάντε κλικ στο κουμπί **Trim** της γραμμής εργαλείων.
2. **Τοποθετήστε τον κέρσορα πάνω από το τμήμα** που θέλετε να αφαιρέσετε — μια προεπισκόπηση επισημαίνει ακριβώς το τμήμα που θα κοπεί.
3. **Κάντε κλικ** για αφαίρεση αυτού του τμήματος.

Η εντολή παραμένει ενεργή μετά από κάθε κόψιμο, ώστε να μπορείτε να συνεχίσετε να τοποθετείτε τον κέρσορα και να κάνετε κλικ για κόψιμο περισσότερων τμημάτων — στην ίδια οντότητα ή σε άλλη. Πατήστε **Escape** για έξοδο.

```
  Πριν:                          Μετά κόψιμο μεσαίου τμήματος:

  ──────●──────●──────           ──────●          ●──────
      τομή    τομή                (αριστερό)    (δεξί τμήμα)
                                  (μεσαίο τμήμα αφαιρέθηκε)
```

## Πώς καθορίζεται το τμήμα κοπής

Η εντολή προβάλλει τη θέση κέρσορα στην οντότητα κάτω από τον κέρσορα και βρίσκει όλα τα σημεία τομής που έχει αυτή η οντότητα με άλλες οντότητες. Αυτές οι τομές χωρίζουν την οντότητα σε τμήματα — για μια Line, Arc, ανοιχτή Polyline ή Spline, τα δικά της άκρα λειτουργούν ως πρόσθετα σταθερά όρια. Ένας πλήρης Circle ή Ellipse, ή μια κλειστή Polyline (συμπεριλαμβανομένου ενός Rectangle), δεν έχει δικά του άκρα, οπότε απαιτούνται τουλάχιστον δύο σημεία τομής πριν μπορέσει καν να κοπεί. Το τμήμα του οποίου το διάστημα περιέχει την προβολή κέρσορα επισημαίνεται και αφαιρείται με κλικ.

- **Line, Arc, ανοιχτή Polyline και Spline** — το τμήμα που αφαιρείται μπορεί να είναι το αρχικό τμήμα (πριν την πρώτη τομή), ένα μεσαίο τμήμα (μεταξύ δύο τομών, χωρίζοντας την οντότητα σε δύο), ή το τελικό τμήμα (μετά την τελευταία τομή).
- **Circle, Ellipse και κλειστή Polyline/Rectangle** — καθώς δεν υπάρχει σταθερή αρχή ή τέλος, μόνο το τόξο μεταξύ δύο *σημείων τομής* μπορεί να αφαιρεθεί. Με λιγότερα από δύο σημεία τομής, δεν εμφανίζεται προεπισκόπηση και το κλικ δεν κάνει τίποτα. Το υπόλοιπο του σχήματος γίνεται το μοναδικό εναπομείναν τμήμα.

## Τι παράγει το κόψιμο

| Οντότητα | Αποτέλεσμα μετά το κόψιμο |
|--------|------------------------|
| Line | Έως δύο μικρότερες οντότητες Line |
| Arc | Έως δύο μικρότερες οντότητες Arc |
| Circle | Μία οντότητα [Arc](../arc/) — το κλειστό σχήμα του κύκλου εξαφανίζεται, οπότε το εναπομείναν τμήμα αποθηκεύεται ως τόξο |
| Ellipse | Μία οντότητα Ellipse με αρχική και τελική γωνία — το εναπομείναν τμήμα παραμένει Ellipse, τώρα μερικό |
| Polyline (ανοιχτή) | Έως δύο μικρότερες οντότητες Polyline |
| Polyline (κλειστή) / Rectangle | Μία ανοιχτή οντότητα Polyline — το κλειστό σχήμα εξαφανίζεται, οπότε το εναπομείναν τμήμα αποθηκεύεται ανοιχτό |
| Spline | Έως δύο μικρότερες οντότητες Spline, προσαρμοσμένες εκ νέου από δειγματοληπτημένα σημεία κατά μήκος της αρχικής καμπύλης |

## Αναφορά πληκτρολογίου

| Πλήκτρο | Ενέργεια |
|---------|----------|
| `Escape` | Έξοδος από λειτουργία trim |

## Υποστηριζόμενες οντότητες

| Οντότητα | Μπορεί να κοπεί; |
|----------|----------------|
| Line | Ναι |
| Arc | Ναι |
| Circle | Ναι — απαιτεί 2 ή περισσότερα σημεία τομής |
| Ellipse | Ναι — απαιτεί 2 ή περισσότερα σημεία τομής |
| Polyline (ανοιχτή) | Ναι |
| Polyline (κλειστή) / Rectangle | Ναι — απαιτεί 2 ή περισσότερα σημεία τομής |
| Spline | Ναι |
| Text, Dimension, Leader | Όχι |

Οι οντότητες που χρησιμοποιούνται ως **όρια κοπής** μπορεί να είναι Line, Arc, Circle, Ellipse, Polyline ή Spline. Οι οντότητες Text, Dimension και Leader δεν καταγράφουν ποτέ τομές, οπότε δεν μπορούν να λειτουργήσουν ούτε ως όρια.

## Trim vs Extend

| | Trim | Extend |
|---|------|--------|
| Τι κάνει | Αφαιρεί τμήμα μιας οντότητας | Τεντώνει τελικό σημείο γραμμής ως όριο |
| Ενεργοποίηση | Hover πάνω από τμήμα που θα κοπεί | Hover κοντά σε τελικό σημείο που θα επεκταθεί |
| Αποτέλεσμα | Η οντότητα χωρίζεται ή συντομεύεται | Το τελικό σημείο γραμμής μετακινείται στο όριο |
| Υποστηριζόμενες οντότητες | Line, Arc, Circle, Ellipse, Polyline, Spline | Μόνο Line |
