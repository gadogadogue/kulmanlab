# New File

Amri ya **New File** husafisha turubai na kuanza mchoro mpya wazi. Jina la kipekee la faili huzalishwa kiotomatiki.

## Jinsi ya kuunda faili mpya

Bonyeza kitufe cha upau wa zana cha **New File** (aikoni ya ukurasa mpya) kwenye paneli ya Faili. Turubai husafishwa mara moja — hakuna maswali au mazungumzo ya uthibitisho.

## Faili mpya ina nini

Faili iliyoundwa upya huanza na:

- **Hakuna vipengele** kwenye turubai.
- **Safu moja ya chaguo-msingi** iitwayo `0` yenye rangi nyeupe na aina ya mstari `Continuous`.
- **Jina la faili lililozalishwa**, `kulman.dxf` — au `kulman (2).dxf`, `kulman (3).dxf`, … ikiwa jina hilo tayari linatumika.

Faili huhifadhiwa kwenye hifadhi ya kivinjari kiotomatiki, inaonekana katika [File Manager](../file-manager/), na inaweza [kubadilishwa jina](../file-manager/#kubadilisha-jina-la-faili) wakati wowote.

## Onyo — kazi ambayo haijahifadhiwa itapotea

Kubonyeza **New File** hutupilia mbali vipengele vyote kwenye turubai ya sasa bila onyo. Kama unataka kuhifadhi mchoro wa sasa, [hamisha](../export-manager/) kwanza.

## Lini kutumia New File dhidi ya Import

| Hali | Kitendo kinachopendekezwa |
|------|--------------------------|
| Kuanza mchoro kutoka mwanzo | **New File** |
| Kufungua faili ya DXF au JSON iliyopo | [Import](../import/) |
| Kunakili mchoro kufanya kazi kwenye toleo | [Hamisha](../export-manager/) faili ya sasa, kisha [ingiza](../import/) nakala |
