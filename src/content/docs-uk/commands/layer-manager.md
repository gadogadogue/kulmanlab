# LayerManager

Команда `LayerManager` відкриває таблицю з усіма шарами кресленика, де **Freeze** (заморожування), **Lock** (блокування), **Plot** (друк), **колір**, **товщину лінії** та **тип лінії** можна редагувати прямо в рядку. Це центральне місце для додавання нових шарів і налаштування поведінки наявних — інші команди шарів ([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/)) виконують кожна одну конкретну дію без відкриття цього вікна.

## Відкриття Layer Manager

- Введіть `LayerManager` у терміналі, **або**
- Натисніть кнопку **Layer Manager** на панелі шарів.

Діалог відкривається як плаваюча панель; заздалегідь нічого вибирати не потрібно.

## Таблиця шарів

| Стовпець | Що контролює |
|----------|----------------|
| Name | Назва шару, показана в таблиці лише для читання (задається один раз, при створенні) |
| Freeze | Приховує об'єкти шару і виключає їх із вибору, доки шар не буде розморожено |
| Lock | Забороняє редагування об'єктів на шарі, не приховуючи їх |
| Plot | Чи включаються об'єкти шару при друку або експорті в PDF |
| Color | Колір ACI шару — клацніть на зразок, щоб відкрити вибір кольору |
| Lineweight | Товщина лінії шару — клацніть на чіп, щоб відкрити вибір товщини |
| Linetype | Візерунок штрихів шару — клацніть на чіп, щоб відкрити вибір типу лінії |

Перемикання Freeze, Lock або Plot діє негайно — окремого кроку збереження немає. Об'єкти, для яких колір, товщина лінії чи тип лінії встановлені як **ByLayer** (значення за замовчуванням), беруть те, що ви задасте тут; об'єкти з власним явним перевизначенням залишаються без змін.

## Додавання шару

1. Натисніть **+ Add Layer** внизу таблиці.
2. Введіть назву та натисніть **Enter** для підтвердження, або **Escape** для скасування.

Назви шарів можуть містити літери, цифри, пробіли та `_`, `-`, `$`. Порожня назва, вже використовувана, або та, що містить інший символ, відхиляється з вбудованим повідомленням про помилку, а рядок залишається відкритим для нової спроби.

Нові шари починають як **розморожені, розблоковані, придатні до друку**, з кольором 7 (білий/чорний), товщиною лінії Default і типом лінії Continuous — ті самі значення за замовчуванням, які [Import](../import/) присвоює шару `0` у порожньому кресленику.

## Що тут неможливо зробити

Кнопки видалення немає — шари ніколи не видаляються після створення, їх можна лише заморозити або залишити невикористаними. Таблиця також не показує, який шар є *поточним*; це задається через випадний список на панелі шарів або через [LayerMakeCurrent](../layer-make-current/), а не через цей діалог.

## Довідник клавіатури

| Клавіша | Дія |
|---------|-----|
| `Enter` | Підтвердити назву нового шару (під час додавання) |
| `Escape` | Скасувати додавання шару, або закрити діалог |

## Пов'язані команди

| Команда | Що робить |
|---------|-----------|
| [LayerMakeCurrent](../layer-make-current/) | Встановити поточний шар відповідно до клікнутого об'єкта |
| [LayerMatch](../layer-match/) | Перепризначити вибрані об'єкти на шар джерельного об'єкта |
| [LayerIsolate](../layer-isolate/) | Заморозити всі шари, крім шарів вибраних об'єктів |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | Розморозити всі шари за один крок |
