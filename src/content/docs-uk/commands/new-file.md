# New File

Команда `new file` негайно починає новий порожній кресленик. Натисніть значок **нової сторінки** на панелі інструментів або введіть `new file` у терміналі.

> **Попередження:** New File **не запитує підтвердження** та **не зберігає** поточний кресленик автоматично. Будь-яка незбережена робота буде втрачена. Якщо потрібно зберегти поточний кресленик — спочатку скористайтеся [Export Manager](../export-manager/).

## Що містить новий файл

- **Жодного об'єкта** на полотні.
- **Один шар за замовчуванням** з назвою `0`, білого кольору та типом лінії `Continuous`.
- **Згенерована назва файлу**, `kulman.dxf` — або `kulman (2).dxf`, `kulman (3).dxf`, … якщо ця назва вже зайнята.

Файл автоматично зберігається у сховище браузера і з'являється в [File Manager](../file-manager/), і його можна [перейменувати](../file-manager/#перейменування-файлу) у будь-який момент.

## New File проти Import

| | New File | Import |
|---|----------|--------|
| Вміст | Порожнє полотно | Вміст вибраного файлу |
| Попередній кресленик | Замінюється (без попередження) | Замінюється (без попередження) |
| Найкраще для | Початок нового кресленика | Відкриття існуючого DXF або JSON |

## Пов'язані команди

- [File Manager](../file-manager/) — переглядати та відновлювати збережені кресленики
- [Export Manager](../export-manager/) — завантажити поточний кресленик перед початком нового
- [Import](../import/) — відкрити існуючий файл замість початку з нуля
