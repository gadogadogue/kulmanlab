# File Manager

`FileManager` ਕਮਾਂਡ ਤੁਹਾਡੇ ਬ੍ਰਾਊਜ਼ਰ ਦੀ ਲੋਕਲ ਸਟੋਰੇਜ ਵਿੱਚ ਸੇਵ ਹਰੇਕ ਡਰਾਇੰਗ ਦਾ ਇੱਕ **ਥੰਬਨੇਲ ਗਰਿੱਡ** ਖੋਲ੍ਹਦੀ ਹੈ, ਹਰੇਕ ਨੂੰ ਆਖਰੀ ਵਾਰ ਸੇਵ ਹੋਣ ਦੇ ਸਮੇਂ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕੀਤਾ ਗਿਆ। ਇਸਦੀ ਵਰਤੋਂ ਪਿਛਲੀ ਡਰਾਇੰਗ ਦੁਬਾਰਾ ਖੋਲ੍ਹਣ, ਉਸਦਾ ਨਾਮ ਬਦਲਣ, ਜਾਂ ਉਸਨੂੰ ਮਿਟਾਉਣ ਲਈ ਕਰੋ।

## File Manager ਖੋਲ੍ਹਣਾ

- ਟਰਮੀਨਲ ਵਿੱਚ `FileManager` ਟਾਈਪ ਕਰੋ, **ਜਾਂ**
- ਸਕ੍ਰੀਨ ਦੇ ਸਿਖਰ 'ਤੇ File ਪੈਨਲ ਵਿੱਚ **File Manager** ਟੂਲਬਾਰ ਬਟਨ (ਹਿਸਟਰੀ ਆਈਕਨ) 'ਤੇ ਕਲਿੱਕ ਕਰੋ।

ਪੈਨਲ ਕੈਨਵਸ ਦੇ ਖੱਬੇ ਪਾਸੇ ਖੁੱਲ੍ਹਦਾ ਹੈ, ਅਤੇ ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਕੋਈ ਹੋਰ ਕਮਾਂਡ ਸ਼ੁਰੂ ਕਰਦੇ ਹੋ ਆਪਣੇ ਆਪ ਬੰਦ ਹੋ ਜਾਂਦਾ ਹੈ।

## ਥੰਬਨੇਲ ਗਰਿੱਡ

ਹਰੇਕ ਸੇਵ ਕੀਤੀ ਡਰਾਇੰਗ ਇੱਕ ਕਾਰਡ ਹੈ ਜੋ ਇੱਕ ਲਾਈਵ-ਰੈਂਡਰ ਕੀਤਾ ਥੰਬਨੇਲ, ਇਸਦਾ ਨਾਮ, ਅਤੇ ਇਹ ਆਖਰੀ ਵਾਰ ਕਦੋਂ ਅੱਪਡੇਟ ਹੋਈ ਦਿਖਾਉਂਦਾ ਹੈ। ਥੰਬਨੇਲ ਹਰ ਵਾਰ ਪੈਨਲ ਖੁੱਲ੍ਹਣ 'ਤੇ ਉਸੇ ਵੇਲੇ ਬਣਾਏ ਜਾਂਦੇ ਹਨ — ਕੁਝ ਵੀ ਪਹਿਲਾਂ ਤੋਂ ਰੈਂਡਰ ਜਾਂ ਸਟੋਰ ਨਹੀਂ ਹੁੰਦਾ — ਇਸ ਲਈ ਥੰਬਨੇਲ ਬਣਦੇ ਸਮੇਂ ਕਾਰਡ ਥੋੜ੍ਹੇ ਸਮੇਂ ਲਈ ਇੱਕ ਪਲੇਸਹੋਲਡਰ ਆਈਕਨ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਹੀ ਪਲੇਸਹੋਲਡਰ ਉਦੋਂ ਵੀ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ ਜੇ ਥੰਬਨੇਲ ਬਣਾਉਣਾ ਅਸਫਲ ਹੋ ਜਾਵੇ, ਜਾਂ ਜੇ ਡਰਾਇੰਗ ਵਿੱਚ ਅਸਲ ਵਿੱਚ ਹਾਲੇ ਕੋਈ ਐਂਟਿਟੀ ਨਾ ਹੋਵੇ।

| ਕਾਰਵਾਈ | ਕਿਵੇਂ |
|--------|-----|
| ਡਰਾਇੰਗ **ਖੋਲ੍ਹੋ** | ਇਸਦੇ ਥੰਬਨੇਲ 'ਤੇ ਕਲਿੱਕ ਕਰੋ — ਮੌਜੂਦਾ ਕੈਨਵਸ ਸਮੱਗਰੀ ਬਦਲ ਦਿੰਦਾ ਹੈ |
| **ਨਾਮ ਬਦਲੋ** | ਪੈਨਸਿਲ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ, ਜਾਂ ਨਾਮ 'ਤੇ ਡਬਲ-ਕਲਿੱਕ ਕਰੋ |
| **ਮਿਟਾਓ** | ਟ੍ਰੈਸ਼ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ, ਫਿਰ ਪੁਸ਼ਟੀ ਕਰੋ |

ਜੇ ਹਾਲੇ ਤੱਕ ਕੋਈ ਫਾਈਲ ਸੇਵ ਨਹੀਂ ਹੋਈ, ਤਾਂ ਪੈਨਲ "No files saved" ਦਿਖਾਉਂਦਾ ਹੈ। ਇੱਕ ਸਕ੍ਰੀਨ 'ਤੇ ਫਿੱਟ ਹੋਣ ਤੋਂ ਵੱਧ ਫਾਈਲਾਂ ਹੋਣ 'ਤੇ, ਗਰਿੱਡ ਦੇ ਹੇਠਾਂ **Page 1 of N** ਕੰਟਰੋਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

## ਫਾਈਲ ਮਿਟਾਉਣਾ

ਟ੍ਰੈਸ਼ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰਨ ਨਾਲ ਤੁਰੰਤ ਮਿਟਦਾ ਨਹੀਂ — ਇਹ ਉਸ ਕਾਰਡ 'ਤੇ ਇੱਕ ਪੁਸ਼ਟੀ ਓਵਰਲੇ ਸਰਗਰਮ ਕਰਦਾ ਹੈ ("Delete this file?" **Delete** / **Cancel** ਬਟਨਾਂ ਨਾਲ), ਕਿਉਂਕਿ ਮਿਟਾਉਣਾ ਪੱਕਾ ਹੈ ਅਤੇ ਵਾਪਸ ਨਹੀਂ ਲਿਆ ਜਾ ਸਕਦਾ। **Cancel** 'ਤੇ ਕਲਿੱਕ ਕਰਨਾ, ਕਿਸੇ ਹੋਰ ਕਾਰਡ ਦੇ ਟ੍ਰੈਸ਼ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰਨਾ, ਜਾਂ ਕਾਰਡ 'ਤੇ ਕਿਤੇ ਹੋਰ ਕਲਿੱਕ ਕਰਨਾ — ਇਹ ਸਭ ਬਿਨਾਂ ਕੁਝ ਮਿਟਾਏ ਬਕਾਇਆ ਪੁਸ਼ਟੀ ਨੂੰ ਛੱਡ ਦਿੰਦੇ ਹਨ।

## ਫਾਈਲ ਦਾ ਨਾਮ ਬਦਲਣਾ

ਪੈਨਸਿਲ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ (ਜਾਂ ਫਾਈਲ ਨਾਮ 'ਤੇ ਡਬਲ-ਕਲਿੱਕ ਕਰੋ) ਇਸਨੂੰ ਥਾਂ 'ਤੇ ਹੀ ਸੰਪਾਦਿਤ ਕਰਨ ਲਈ, ਫਿਰ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ **Enter** ਜਾਂ ਰੱਦ ਕਰਨ ਲਈ **Escape** ਦਬਾਓ। ਨਾਮ ਬਦਲਣ ਦੀ ਬੇਨਤੀ ਰੱਦ ਹੋ ਜਾਂਦੀ ਹੈ ਜੇ ਨਵਾਂ ਨਾਮ:

- ਖਾਲੀ ਹੋਵੇ, ਜਾਂ 100 ਅੱਖਰਾਂ ਤੋਂ ਲੰਬਾ ਹੋਵੇ,
- ਪਹਿਲਾਂ ਹੀ ਕਿਸੇ ਹੋਰ ਸੇਵ ਕੀਤੀ ਫਾਈਲ ਦੁਆਰਾ ਵਰਤਿਆ ਜਾ ਰਿਹਾ ਹੋਵੇ (ਅੱਖਰਾਂ ਦੇ ਕੇਸ ਦੀ ਪਰਵਾਹ ਕੀਤੇ ਬਿਨਾਂ),
- ਇੱਕ ਬਿੰਦੀ ਨਾਲ ਖਤਮ ਹੁੰਦਾ ਹੋਵੇ, ਜਾਂ
- Windows ਦਾ ਰਾਖਵਾਂ ਡਿਵਾਈਸ ਨਾਮ ਹੋਵੇ ਜਿਵੇਂ `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, ਜਾਂ `LPT1`–`LPT9`।

ਫਾਈਲ ਨਾਮ ਵਿੱਚ ਅਵੈਧ ਅੱਖਰ (`\ / : * ? " < > |`) ਟਾਈਪ ਕਰਦੇ ਸਮੇਂ ਆਪਣੇ ਆਪ ਹਟ ਜਾਂਦੇ ਹਨ। ਨਾਮ ਬਦਲਣ ਨਾਲ ਸਿਰਫ਼ ਲੇਬਲ ਬਦਲਦਾ ਹੈ — ਇਹ ਗਰਿੱਡ ਵਿੱਚ ਫਾਈਲ ਦੀ ਸਥਿਤੀ ਨੂੰ ਪ੍ਰਭਾਵਿਤ ਨਹੀਂ ਕਰਦਾ, ਕਿਉਂਕਿ ਇਹ ਨਾਮ ਦੁਆਰਾ ਨਹੀਂ, ਆਖਰੀ-ਸੇਵ ਸਮੇਂ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਹੁੰਦੀ ਹੈ।

## ਆਪਣਾ ਕੰਮ ਬੈਕਅੱਪ ਕਰੋ — ਬ੍ਰਾਊਜ਼ਰ ਸਟੋਰੇਜ ਸਥਾਈ ਨਹੀਂ ਹੈ

KulmanLab ਡਰਾਇੰਗਾਂ ਨੂੰ **IndexedDB** ਵਿੱਚ ਸੇਵ ਕਰਦਾ ਹੈ, ਇੱਕ ਡਾਟਾਬੇਸ ਜੋ ਤੁਹਾਡੇ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਬਿਲਟ-ਇਨ ਹੈ:

- ਫਾਈਲਾਂ **ਸਿਰਫ਼ ਤੁਹਾਡੀ ਡਿਵਾਈਸ 'ਤੇ ਸਥਾਨਕ ਤੌਰ 'ਤੇ** ਸਟੋਰ ਹੁੰਦੀਆਂ ਹਨ — ਕੁਝ ਵੀ ਸਰਵਰ 'ਤੇ ਅੱਪਲੋਡ ਨਹੀਂ ਹੁੰਦਾ।
- ਹਰ ਬ੍ਰਾਊਜ਼ਰ ਅਤੇ ਡਿਵਾਈਸ ਦੀ ਆਪਣੀ ਸੁਤੰਤਰ ਸਟੋਰੇਜ ਹੁੰਦੀ ਹੈ। ਇੱਕ ਕੰਪਿਊਟਰ 'ਤੇ Chrome ਵਿੱਚ ਸੇਵ ਕੀਤੀ ਡਰਾਇੰਗ Firefox ਵਿੱਚ, ਜਾਂ ਕਿਸੇ ਹੋਰ ਮਸ਼ੀਨ 'ਤੇ ਦਿਖਾਈ ਨਹੀਂ ਦਿੰਦੀ।
- ਇਹ ਸਟੋਰੇਜ **ਬਿਨਾਂ ਚੇਤਾਵਨੀ ਦੇ ਸਾਫ਼ ਹੋ ਸਕਦੀ ਹੈ** — ਸਾਈਟ ਡਾਟਾ ਜਾਂ ਬ੍ਰਾਊਜ਼ਿੰਗ ਹਿਸਟਰੀ ਸਾਫ਼ ਕਰਨ ਨਾਲ, ਡਿਸਕ ਸਪੇਸ ਘੱਟ ਹੋਣ 'ਤੇ, ਪ੍ਰਾਈਵੇਟ/ਇਨਕੋਗਨਿਟੋ ਵਿੰਡੋ ਵਰਤਣ ਨਾਲ, ਬ੍ਰਾਊਜ਼ਰ ਜਾਂ OS ਦੁਬਾਰਾ ਇੰਸਟਾਲ ਕਰਨ ਨਾਲ, ਜਾਂ ਡਿਵਾਈਸ ਬਦਲਣ ਨਾਲ। ਇਹਨਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਤੁਹਾਨੂੰ ਉੱਥੇ ਮੌਜੂਦ ਚੀਜ਼ ਵਾਪਸ ਲੈਣ ਦਾ ਮੌਕਾ ਨਹੀਂ ਦਿੰਦਾ।

**ਡਰਾਇੰਗ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਣ ਦਾ ਇੱਕੋ-ਇੱਕ ਭਰੋਸੇਯੋਗ ਤਰੀਕਾ ਹੈ ਇਸਨੂੰ ਆਪਣੀ ਖੁਦ ਦੀ ਸਟੋਰੇਜ ਵਿੱਚ [export](../export/) ਕਰਨਾ।** ਜਦੋਂ ਵੀ ਸੰਭਵ ਹੋਵੇ `.json` (KulmanLab ਦਾ ਨੇਟਿਵ ਫਾਰਮੈਟ) ਵਰਤੋ — ਇਹ ਹਰੇਕ ਐਂਟਿਟੀ ਨੂੰ ਬਿਲਕੁਲ ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ; ਜਦੋਂ ਤੁਹਾਨੂੰ ਹੋਰ CAD ਟੂਲਾਂ ਨਾਲ ਅਨੁਕੂਲਤਾ ਚਾਹੀਦੀ ਹੋਵੇ ਤਾਂ `.dxf` ਵਰਤੋ। ਜੋ ਵੀ ਗੁਆਉਣ 'ਤੇ ਤੁਹਾਨੂੰ ਦੁੱਖ ਹੋਵੇ ਉਸ ਲਈ ਇਹ ਕਰੋ, ਅਤੇ ਬ੍ਰਾਊਜ਼ਰ ਡਾਟਾ ਸਾਫ਼ ਕਰਨ, ਬ੍ਰਾਊਜ਼ਰ ਜਾਂ ਡਿਵਾਈਸ ਬਦਲਣ, ਜਾਂ ਮਸ਼ੀਨ ਨੂੰ ਕੁਝ ਸਮੇਂ ਲਈ ਪਾਸੇ ਰੱਖਣ ਤੋਂ ਪਹਿਲਾਂ ਵੀ ਇਹ ਕਰੋ।

## ਸਟਾਰਟਅੱਪ 'ਤੇ ਆਪਣੇ ਆਪ ਫਾਈਲ ਲੋਡਿੰਗ

ਜਦੋਂ ਤੁਸੀਂ KulmanLab CAD ਖੋਲ੍ਹਦੇ ਹੋ, ਐਪ ਆਪਣੇ ਆਪ ਸਟੋਰੇਜ ਤੋਂ **ਸਭ ਤੋਂ ਹਾਲ ਹੀ ਵਿੱਚ ਸੋਧੀ ਫਾਈਲ** ਲੋਡ ਕਰਦਾ ਹੈ। ਤੁਹਾਨੂੰ ਹਰ ਵਾਰ File Manager ਤੋਂ ਹੱਥੀਂ ਖੋਲ੍ਹਣ ਦੀ ਲੋੜ ਨਹੀਂ।

## ਸਟੋਰੇਜ ਦਾ ਪ੍ਰਬੰਧਨ

ਤੁਸੀਂ ਕਿੰਨੀਆਂ ਡਰਾਇੰਗਾਂ ਸੇਵ ਕਰ ਸਕਦੇ ਹੋ ਇਸਦੀ ਕੋਈ ਪੱਕੀ ਸੀਮਾ ਨਹੀਂ ਹੈ, ਪਰ ਬ੍ਰਾਊਜ਼ਰ ਸਟੋਰੇਜ ਸੀਮਿਤ ਹੈ। ਜੇ ਤੁਹਾਨੂੰ ਸਟੋਰੇਜ ਚੇਤਾਵਨੀਆਂ ਦਿਖਾਈ ਦੇਣ, ਤਾਂ File Manager ਤੋਂ ਪੁਰਾਣੀਆਂ ਫਾਈਲਾਂ ਹਟਾਓ — ਜਾਂ ਹੋਰ ਵਧੀਆ, ਪਹਿਲਾਂ ਉਹਨਾਂ ਨੂੰ ਐਕਸਪੋਰਟ ਕਰੋ ਤਾਂ ਜੋ ਕੁਝ ਵੀ ਗੁਆਚੇ ਨਾ।

ਇੱਕੋ ਵਾਰ ਵਿੱਚ ਸਾਰੀਆਂ ਸੇਵ ਕੀਤੀਆਂ ਡਰਾਇੰਗਾਂ ਹਟਾਉਣ ਲਈ, [WipeStorage](../wipestorage/) ਕਮਾਂਡ ਵਰਤੋ।

## ਫਾਈਲ ਨਾਮ

ਨਵੀਆਂ ਅਤੇ ਇੰਪੋਰਟ ਕੀਤੀਆਂ ਫਾਈਲਾਂ ਨੂੰ ਇੱਕ ਸਾਦਾ ਨਾਮ ਮਿਲਦਾ ਹੈ — ਕੋਈ ਟਾਈਮਸਟੈਂਪ ਨਹੀਂ ਜੋੜਿਆ ਜਾਂਦਾ। ਜੇ ਉਹ ਨਾਮ ਪਹਿਲਾਂ ਹੀ ਵਰਤਿਆ ਜਾ ਚੁੱਕਾ ਹੈ, ਤਾਂ Finder/Explorer ਵਾਂਗ ਇੱਕ ਪਿਛੇਤਰ ਆਪਣੇ ਆਪ ਜੋੜਿਆ ਜਾਂਦਾ ਹੈ (`plan (2)`, `plan (3)`, …) ਤਾਂ ਜੋ ਕੁਝ ਵੀ ਓਵਰਰਾਈਟ ਨਾ ਹੋਵੇ। ਤੁਸੀਂ ਬਾਅਦ ਵਿੱਚ ਹਮੇਸ਼ਾ [ਨਾਮ ਬਦਲ ਕੇ](#ਫਾਈਲ-ਦਾ-ਨਾਮ-ਬਦਲਣਾ) ਫਾਈਲ ਨੂੰ ਵਧੇਰੇ ਸਪਸ਼ਟ ਨਾਮ ਦੇ ਸਕਦੇ ਹੋ।
