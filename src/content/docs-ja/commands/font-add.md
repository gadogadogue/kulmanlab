# FontAdd

`FontAdd` コマンドは、先に [Font Manager](../font-manager/) ダイアログを開くことなくカスタム `.ttf` フォントをアップロードするため、システムのファイル選択ダイアログを開きます。Font Manager の **Add Font** ボタンが実行するのと同じアップロードです — FontAdd はターミナルからそこへ直接アクセスする手段にすぎません。

## フォントをアップロードする

1. ターミナルに `FontAdd` と入力するか、[Font Manager](../font-manager/) ダイアログ下部の **Add Font** をクリックします。
2. システムのファイル選択ダイアログで `.ttf` ファイルを選びます。対応しているのは TrueType フォントのみです — `.otf` や `.woff`/`.woff2` には対応していません。

ファイル選択ダイアログが開いた時点でコマンドは完了します — その後にクリックやターミナル入力は続きません。ファイルを選んだ時点でフォントが登録され、**User** グループに表示されます。

## アップロード時に起こること

- ファイル名(拡張子を除く)がフォント名になります。`MyFont.ttf` をアップロードすると、`MyFont` という名前のフォントが追加されます。
- 既存のカスタムフォントと同じ名前のファイルをアップロードすると、そのフォントを**置き換えます**。
- フォントはブラウザ(IndexedDB)に永続的に保存され、次回 KulmanLab CAD を開いたときに自動的に再読み込みされます — 現在の図面には紐付いていません。

## キーボードリファレンス

FontAdd にはそれ自体のキーボード操作はありません — コマンドの全体がブラウザのネイティブなファイル選択ダイアログで構成されています。そのダイアログをキャンセルする(またはファイルを選ばない)と、フォントリストは変更されないままです。

| コマンド | 機能 |
