# Hatch Manager

`HatchManager` 命令会打开一个对话框，用于浏览带有实时样本预览的 hatch 图案，以及上传你自己的 `.pat` 图案文件以配合 [Hatch](../hatch/) 使用。

## 打开 Hatch Manager

在终端输入 `HatchManager`。这与点击 hatch 的 **Pattern** 芯片时打开的图案选择器不同 —— 选择器为单个 hatch 选择图案，而 Hatch Manager 是你添加或移除 `.pat` 文件的地方。

## 图案分组

| 分组 | 内容 |
|------|------|
| **User** | 来自你自己上传的 `.pat` 文件的图案，按每个图案来源的文件进一步分组（仅在你上传一个文件后才会显示） |
| **Standard** | `SOLID` 加上该图形自身的图案表 —— 每个新图形都以相同的内置图案库开始，就像其图层和线型一样 |

点击列表中的任意图案（或使用 `↑`/`↓`）即可在右侧预览它 —— 该样本使用与画布填充时相同的代码绘制，因此它正是图形将要显示的内容，同时还会显示图案的名称、描述和线条数量。

## 上传自定义图案文件

1. 点击对话框底部的 **Add .pat File**。
2. 选择一个 `.pat` 文件 —— 标准的 hatch 图案格式。单个文件通常会一次定义许多具名图案；它们都会作为按该文件名称分组的独立条目出现。
3. 上传的文件会永久保存在浏览器中（IndexedDB），按最近添加的排在最前，并在你下次打开 KulmanLab CAD 时自动重新加载。

上传定义了与某个内置图案同名图案的文件会**覆盖**默认值 —— 这是获取 Autodesk 官方图案定义的受支持方式：上传真正的 `acad.pat`，其中 ANSI31 及其他标准名称的版本就会取代 KulmanLab 自身的近似实现。

如果某个图形引用了一个你的图案库中没有的图案名称 —— 例如从使用了你尚未上传的 `acad.pat` 中某个图案的 DXF 导入而来 —— hatch 仍会渲染，使用 `ANSI31` 作为替代，而不是回退为平面、无图案的填充。

## 移除图案文件

点击 **User** 分组中文件名旁的 **×**，即可将该文件及其定义的每个图案一并移除。任何已经使用其中某个图案的 hatch 会立即回退为 `ANSI31`。内置的 **Standard** 图案无法移除。

## 键盘参考

| 按键 | 操作 |
|------|------|
| `↑` / `↓` | 在图案列表中上下移动选择 |
| `Escape` | 关闭 Hatch Manager |
