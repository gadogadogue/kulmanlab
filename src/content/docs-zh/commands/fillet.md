# Fillet

`fillet`(圆角)命令通过插入给定半径的切弧,将选中的图元修剪(或合并)至该点,从而把两条 [Line](../line/)、[Arc](../arc/) 或 [Polyline](../polyline/) 线段之间的角变为圆角。

圆角适用于 **Line、Arc 和 Polyline** 图元 — 包括多段线自身的直线段或弧形段。

## 使用圆角

1. 在命令行中输入 `fillet`,或单击工具栏中的 **Fillet** 按钮。
2. **输入圆角半径**并按 **Enter** 键。
3. **单击第一条直线、圆弧或多段线线段** — 单击位置决定在任意交点的哪一侧保留。
4. **将光标悬停在第二个图元上** — 虚线弧预览显示产生的圆角效果。将光标移至要保留的一侧。
5. **单击**以应用。

```
  之前:                     圆角后(半径 r):

  ──────────────              ──────────╮
                │                        ╰────
                │
```

## 相交图元的边侧选择

当两个图元相互交叉时,圆角应用于由单击位置定义的角 — 每个图元上**与光标同侧**的部分被保留。

- 单击第一个图元的一端附近以选择该半部分。
- 将光标移到第二个图元的所需半部分 — 虚线预览实时更新。

## 命令创建的内容

结果取决于您选择的内容:

- **两个独立的 Line/Arc 图元**,或任何不涉及开放多段线的组合:两者都被修剪至切点 **T1**/**T2**,并在它们之间插入一条新的 Arc 图元。
- **共享一个角顶点的同一多段线的两条线段**:不产生新图元 — 圆角成为多段线本身的一部分。角顶点被替换为两个切点,它们之间的圆弧作为该边的 bulge 值保存 — 与倒圆角的多段线转角在 DXF 中往返转换的方式完全相同。
- **涉及开放多段线的其他所有情况** — 两条不同的开放多段线,或一条开放多段线和一个独立的 Line/Arc:两者都合并为**一条新的多段线**,每一侧都保留到各自的切点,并由圆角弧作为额外的 bulge 线段连接,取代原有图元。

插入或延伸的圆弧继承当前的线宽、颜色、图层和线型设置(如果并入多段线,则继承多段线自身的设置)。

## 没有真正角度可倒圆角的转角

如果选中的两条线段已经在共享顶点处相切 — 一个笔直的多段线转角,或一条平滑过渡到切线延续弧形段的直线 — 就不存在圆能够倒圆角的真正转角。圆角命令会检测到这一点,并以 `cannot fillet: no tangent circle fits there` 拒绝操作,而不是画出一个不需要的圈。

## 键盘参考

| 按键 | 操作 |
|-----|--------|
| `0`–`9`、`.` | 在半径值后追加数字 |
| `Backspace` | 删除最后输入的字符 |
| `Enter` / `空格` | 确认输入的半径并进入图元选择 |
| `Escape` | 取消并重置 |

## 支持的图元

| 图元 | 是否支持 |
|--------|-----------|
| Line | 是 |
| Arc | 是 |
| Polyline(直线段或弧形段) | 是 |
| Circle、Ellipse | 否 |
| Text、Spline、Dimension、Leader | 否 |

## Fillet vs Chamfer

| | 圆角 | 倒角 |
|---|--------|---------|
| 角的类型 | 圆弧圆角 | 直线切割 |
| 输入 | 一个半径 | 两个距离(d1, d2) |
| 插入图元 | 圆弧 | 直线 |
| 支持的图元 | Line、Arc 和 Polyline(直线段或弧形段) | Line 和 Polyline(仅直线段) |
