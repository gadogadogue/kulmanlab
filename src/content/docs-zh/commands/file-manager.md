# File Manager

`FileManager` 命令会打开一个**缩略图网格**，展示所有已保存到浏览器本地存储的图形，按每个文件最后保存的时间排序。使用它可以重新打开以前的图形、重命名，或将其删除。

## 打开 File Manager

- 在终端中输入 `FileManager`，**或**
- 点击屏幕顶部文件面板中的 **File Manager** 工具栏按钮（历史图标）。

面板会在画布左侧打开，并在您开始执行其他命令或[导入](../import/)文件时自动关闭 — 因此它绝不会停留在一个尚未列出的图形之上。它每次都会以最新的列表重新打开。

## 缩略图网格

每个已保存的图形都是一张卡片，显示实时渲染的缩略图、名称，以及最后更新的时间。缩略图会在每次打开面板时即时生成 — 没有任何内容是预先渲染或存储的 — 因此在缩略图绘制期间，卡片会短暂显示一个占位图标。如果生成失败，或者图形确实还没有任何实体，也会显示相同的占位图标。

| 操作 | 方法 |
|--------|-----|
| **打开**图形 | 点击其缩略图 — 替换当前画布内容 |
| **重命名** | 点击铅笔图标，或双击名称 |
| **删除** | 点击垃圾桶图标，然后确认 |

如果尚未保存任何文件，面板会显示 "No files saved"。当文件数量超出一屏可容纳的范围时，网格下方会出现 **Page 1 of N** 控件。

当前在编辑器中打开的文件的卡片会以强调色的圆环标记，且**没有删除按钮** — 删除打开的文件会清空其已保存的数据，而画布仍在显示它，下一次编辑又会立即将其重新保存回去。重命名该文件仍然可用。

## 删除文件

点击垃圾桶图标不会立即删除 — 它会在该卡片上激活一个确认叠层（"Delete this file?" 以及 **Delete** / **Cancel** 按钮），因为删除是永久性的且无法撤销。点击 **Cancel**、点击另一张卡片的垃圾桶图标，或点击卡片上的其他位置，都会取消待处理的确认而不删除任何内容。

## 重命名文件

点击铅笔图标（或双击文件名）即可就地编辑，然后按 **Enter** 确认或按 **Escape** 取消。若新名称满足以下任一情况，重命名将被拒绝：

- 为空，或超过 100 个字符，
- 已被另一个已保存文件使用（不区分大小写），
- 以句点结尾，或
- 是 Windows 保留的设备名称，例如 `CON`、`PRN`、`AUX`、`NUL`、`COM1`–`COM9`，或 `LPT1`–`LPT9`。

文件名中不允许使用的字符（`\ / : * ? " < > |`）会在您输入时自动移除。重命名只会更改标签 — 不会影响图形在网格中的位置，因为排序依据是最后保存时间，而非名称。

## 备份您的作品 — 浏览器存储并非永久保存

KulmanLab 将图形保存在 **IndexedDB** 中，这是内置于您浏览器中的数据库：

- 文件**仅存储在您的设备本地** — 不会上传到任何服务器。
- 每个浏览器和设备都有各自独立的存储。在一台电脑的 Chrome 中保存的图形不会出现在 Firefox 中，也不会出现在其他设备上。
- 这种存储**可能在没有任何警告的情况下被清除** — 例如清除网站数据或浏览历史、磁盘空间不足、使用隐私/无痕窗口、重新安装浏览器或操作系统，或更换设备。以上任何一种情况都不会给您恢复原有内容的机会。

**保证图形安全的唯一可靠方法是将其[导出](../export-manager/)到您自己的存储中。** 尽可能使用 `.json`（KulmanLab 的原生格式）— 它能精确保留每个实体；如果需要与其他 CAD 工具兼容，请使用 `.dxf`。对任何您不想丢失的内容都应这样做，并在清除浏览器数据、更换浏览器或设备、或长时间搁置设备之前进行。

## 启动时自动加载文件

打开 KulmanLab CAD 时，应用程序会自动从存储中加载**最近修改的文件**。您无需每次都从 File Manager 手动打开它。

## 管理存储

可保存的图形数量没有固定限制，但浏览器存储是有限的。如果您注意到存储警告，请从 File Manager 中删除较旧的文件 — 或者更好的做法是，先将它们导出，以免丢失任何内容。

要一次性删除所有已保存的图形，请使用 [WipeStorage](../wipestorage/) 命令。

## 文件名

新建和导入的文件会获得一个简单的名称 — 不会内嵌时间戳。如果该名称已被占用，系统会自动添加类似 Finder/资源管理器风格的后缀（`plan (2)`、`plan (3)`，……），以确保不会覆盖任何内容。您随时可以之后使用[重命名](#重命名文件)为文件起一个更清晰的名称。
