# FontAdd

คำสั่ง `FontAdd` เปิดตัวเลือกไฟล์ของระบบเพื่ออัปโหลดฟอนต์ `.ttf` กำหนดเอง โดยไม่ต้องเปิดกล่องโต้ตอบ [Font Manager](../font-manager/) ก่อน เป็นการอัปโหลดแบบเดียวกับที่ปุ่ม **Add Font** ใน Font Manager เรียกใช้ — FontAdd เป็นเพียงทางลัดตรงไปยังจุดนั้นจากเทอร์มินัล

## การอัปโหลดฟอนต์

1. พิมพ์ `FontAdd` ในเทอร์มินัล หรือคลิก **Add Font** ที่ส่วนท้ายของกล่องโต้ตอบ [Font Manager](../font-manager/)
2. เลือกไฟล์ `.ttf` ในตัวเลือกไฟล์ของระบบ รองรับเฉพาะฟอนต์ TrueType เท่านั้น — ไม่รองรับ `.otf` และ `.woff`/`.woff2`

คำสั่งจะสิ้นสุดทันทีที่ตัวเลือกไฟล์เปิดขึ้น — ไม่มีการคลิกหรือป้อนข้อมูลในเทอร์มินัลเพิ่มเติมอีก ฟอนต์จะถูกลงทะเบียนและปรากฏในกลุ่ม **User** ทันทีที่เลือกไฟล์

## สิ่งที่เกิดขึ้นเมื่ออัปโหลด

- ชื่อไฟล์ (ไม่รวมนามสกุล) จะกลายเป็นชื่อฟอนต์ การอัปโหลด `MyFont.ttf` จะเพิ่มฟอนต์ชื่อ `MyFont`
- การอัปโหลดไฟล์ที่มีชื่อตรงกับฟอนต์กำหนดเองที่มีอยู่แล้วจะ **แทนที่** ฟอนต์นั้น
- ฟอนต์จะถูกบันทึกไว้อย่างถาวรในเบราว์เซอร์ (IndexedDB) และโหลดขึ้นมาใหม่โดยอัตโนมัติในครั้งถัดไปที่คุณเปิด KulmanLab CAD — ไม่ได้ผูกติดกับภาพวาดปัจจุบัน

## อ้างอิงแป้นพิมพ์

FontAdd ไม่มีการโต้ตอบด้วยแป้นพิมพ์ของตัวเอง — คำสั่งทั้งหมดประกอบด้วยกล่องโต้ตอบตัวเลือกไฟล์ดั้งเดิมของเบราว์เซอร์เท่านั้น การยกเลิกกล่องโต้ตอบนั้น (หรือไม่เลือกไฟล์ใดๆ) จะทำให้รายการฟอนต์ไม่เปลี่ยนแปลง
