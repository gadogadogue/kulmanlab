# File Manager

คำสั่ง `FileManager` เปิด **กริดภาพขนาดย่อ** ของภาพวาดทุกชิ้นที่ถูกบันทึกไปยังหน่วยความจำในเครื่องของเบราว์เซอร์ เรียงตามเวลาที่บันทึกล่าสุดของแต่ละไฟล์ ใช้เพื่อเปิดภาพวาดก่อนหน้าอีกครั้ง เปลี่ยนชื่อ หรือลบทิ้ง

## การเปิด File Manager

- พิมพ์ `FileManager` ในเทอร์มินัล **หรือ**
- คลิกปุ่มแถบเครื่องมือ **File Manager** (ไอคอนประวัติ) ในแผง File ที่ด้านบนของหน้าจอ

แผงจะเปิดที่ด้านซ้ายของแคนวาส และปิดโดยอัตโนมัติทันทีที่คุณเริ่มคำสั่งอื่น

## กริดภาพขนาดย่อ

ภาพวาดที่บันทึกแต่ละชิ้นจะแสดงเป็นการ์ดที่มีภาพขนาดย่อที่เรนเดอร์แบบสด ชื่อของมัน และเวลาที่อัปเดตล่าสุด ภาพขนาดย่อจะถูกสร้างขึ้นทันทีทุกครั้งที่เปิดแผง — ไม่มีอะไรถูกเรนเดอร์หรือจัดเก็บไว้ล่วงหน้า — ดังนั้นการ์ดจะแสดงไอคอนตัวยึดตำแหน่งชั่วครู่ขณะที่ภาพขนาดย่อกำลังถูกวาด ไอคอนตัวยึดตำแหน่งเดียวกันจะปรากฏด้วยหากการสร้างล้มเหลว หรือหากภาพวาดยังไม่มีวัตถุใดๆ เลย

| การกระทำ | วิธีทำ |
|--------|-----|
| **เปิด** ภาพวาด | คลิกภาพขนาดย่อของมัน — แทนที่เนื้อหาปัจจุบันของแคนวาส |
| **เปลี่ยนชื่อ** | คลิกไอคอนดินสอ หรือดับเบิลคลิกที่ชื่อ |
| **ลบ** | คลิกไอคอนถังขยะ แล้วยืนยัน |

หากยังไม่มีไฟล์ที่บันทึก แผงจะแสดง "No files saved" หากมีไฟล์มากกว่าที่จะแสดงได้ในหน้าจอเดียว ตัวควบคุม **Page 1 of N** จะปรากฏด้านล่างกริด

## การลบไฟล์

การคลิกไอคอนถังขยะจะไม่ลบทันที — แต่จะเปิดใช้งานการยืนยันซ้อนทับบนการ์ดนั้น ("Delete this file?" พร้อมปุ่ม **Delete** / **Cancel**) เนื่องจากการลบเป็นการถาวรและไม่สามารถยกเลิกได้ การคลิก **Cancel** การคลิกไอคอนถังขยะของการ์ดอื่น หรือการคลิกที่อื่นบนการ์ด ล้วนยกเลิกการยืนยันที่ค้างอยู่โดยไม่ลบสิ่งใด

## การเปลี่ยนชื่อไฟล์

คลิกไอคอนดินสอ (หรือดับเบิลคลิกที่ชื่อไฟล์) เพื่อแก้ไขทันที จากนั้นกด **Enter** เพื่อยืนยันหรือ **Escape** เพื่อยกเลิก การเปลี่ยนชื่อจะถูกปฏิเสธหากชื่อใหม่:

- ว่างเปล่า หรือยาวเกิน 100 ตัวอักษร
- ถูกใช้แล้วโดยไฟล์ที่บันทึกไว้อื่น (ไม่สนใจตัวพิมพ์ใหญ่/เล็ก)
- ลงท้ายด้วยจุด หรือ
- เป็นชื่ออุปกรณ์ที่ Windows สงวนไว้ เช่น `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, หรือ `LPT1`–`LPT9`

อักขระที่ไม่ถูกต้องในชื่อไฟล์ (`\ / : * ? " < > |`) จะถูกลบออกโดยอัตโนมัติขณะที่คุณพิมพ์ การเปลี่ยนชื่อจะเปลี่ยนเฉพาะป้ายชื่อเท่านั้น — ไม่ส่งผลต่อตำแหน่งของภาพวาดในกริด เนื่องจากเรียงตามเวลาบันทึกล่าสุด ไม่ใช่ตามชื่อ

## สำรองข้อมูลงานของคุณ — หน่วยความจำเบราว์เซอร์ไม่ถาวร

KulmanLab บันทึกภาพวาดไปยัง **IndexedDB** ซึ่งเป็นฐานข้อมูลที่ติดตั้งอยู่ในเบราว์เซอร์ของคุณ:

- ไฟล์ถูกจัดเก็บ **ในเครื่องของคุณเท่านั้น** — ไม่มีสิ่งใดถูกอัปโหลดไปยังเซิร์ฟเวอร์
- แต่ละเบราว์เซอร์และอุปกรณ์มีหน่วยเก็บข้อมูลอิสระของตัวเอง ภาพวาดที่บันทึกใน Chrome บนคอมพิวเตอร์เครื่องหนึ่งจะไม่ปรากฏใน Firefox หรือบนอุปกรณ์อื่น
- หน่วยเก็บข้อมูลนี้ **อาจถูกล้างโดยไม่มีการเตือน** — จากการล้างข้อมูลไซต์หรือประวัติการท่องเว็บ พื้นที่ดิสก์ไม่เพียงพอ การใช้หน้าต่างส่วนตัว/ไม่ระบุตัวตน การติดตั้งเบราว์เซอร์หรือระบบปฏิบัติการใหม่ หรือการเปลี่ยนอุปกรณ์ ไม่มีสถานการณ์ใดในนี้ที่จะให้โอกาสคุณกู้คืนสิ่งที่เคยมีอยู่

**วิธีเดียวที่เชื่อถือได้ในการรักษาภาพวาดให้ปลอดภัยคือการ [ส่งออก](../export/) ไปยังพื้นที่จัดเก็บของคุณเอง** ใช้ `.json` (รูปแบบดั้งเดิมของ KulmanLab) เมื่อเป็นไปได้ — จะรักษาทุกวัตถุไว้อย่างแม่นยำ; ใช้ `.dxf` เมื่อคุณต้องการความเข้ากันได้กับเครื่องมือ CAD อื่นๆ ทำเช่นนี้กับทุกสิ่งที่คุณจะเสียใจหากสูญหาย และก่อนที่จะล้างข้อมูลเบราว์เซอร์ เปลี่ยนเบราว์เซอร์หรืออุปกรณ์ หรือเก็บเครื่องไว้สักระยะหนึ่ง

## การโหลดไฟล์อัตโนมัติเมื่อเริ่มต้น

เมื่อคุณเปิด KulmanLab CAD แอปจะโหลด **ไฟล์ที่แก้ไขล่าสุด** จากหน่วยเก็บข้อมูลโดยอัตโนมัติ คุณไม่ต้องเปิดด้วยตนเองจาก File Manager ทุกครั้ง

## การจัดการพื้นที่เก็บข้อมูล

ไม่มีขีดจำกัดตายตัวสำหรับจำนวนภาพวาดที่คุณสามารถบันทึกได้ แต่หน่วยเก็บข้อมูลเบราว์เซอร์มีจำกัด หากคุณพบคำเตือนเกี่ยวกับพื้นที่เก็บข้อมูล ให้ลบไฟล์เก่าจาก File Manager — หรือควรส่งออกไฟล์เหล่านั้นก่อนเพื่อไม่ให้สูญเสียสิ่งใด

หากต้องการลบภาพวาดที่บันทึกทั้งหมดพร้อมกัน ใช้คำสั่ง [WipeStorage](../wipestorage/)

## ชื่อไฟล์

ไฟล์ใหม่และไฟล์ที่นำเข้าจะได้รับชื่อธรรมดา — ไม่มีการฝังการประทับเวลา หากชื่อนั้นถูกใช้แล้ว ส่วนต่อท้ายสไตล์ Finder/Explorer จะถูกเพิ่มโดยอัตโนมัติ (`plan (2)`, `plan (3)`, …) เพื่อไม่ให้มีสิ่งใดถูกเขียนทับ คุณสามารถตั้งชื่อไฟล์ให้ชัดเจนขึ้นในภายหลังได้เสมอโดยใช้[การเปลี่ยนชื่อ](#การเปลี่ยนชื่อไฟล์)

## คำสั่งที่เกี่ยวข้อง

- [Import](../import/) — โหลดภาพวาดจากระบบไฟล์ของคุณไปยังหน่วยความจำเบราว์เซอร์
- [Export](../export/) — ดาวน์โหลดภาพวาดไปยังระบบไฟล์ของคุณ
- [New File](../new-file/) — เริ่มภาพวาดเปล่า (บันทึกอัตโนมัติด้วย)
- [WipeStorage](../wipestorage/) — ล้างไฟล์ที่บันทึกทั้งหมดจากหน่วยความจำเบราว์เซอร์
