# Fillet

คำสั่ง `fillet` ทำมุมโค้งระหว่างส่วน [Line](../line/), [Arc](../arc/) หรือ [Polyline](../polyline/) สองส่วนโดยแทรกส่วนโค้งสัมผัสที่มีรัศมีที่กำหนด และตัด (หรือรวม) วัตถุที่เลือกกลับไปยังจุดนั้น

Fillet ทำงานกับวัตถุ **Line, Arc และ Polyline** — รวมถึงส่วนตรงหรือส่วนโค้งของ polyline เอง

## การใช้ Fillet

1. พิมพ์ `fillet` ในเทอร์มินัลหรือคลิกปุ่ม **Fillet** บนแถบเครื่องมือ
2. **พิมพ์รัศมี fillet** แล้วกด **Enter**
3. **คลิกเส้น ส่วนโค้ง หรือส่วน polyline แรก** — ส่วนที่คุณคลิกกำหนดว่าด้านใดของจุดตัดจะถูกเก็บไว้
4. **วางเมาส์เหนือวัตถุที่สอง** — ตัวอย่างส่วนโค้งประแสดง fillet ที่ได้ ย้ายเคอร์เซอร์ไปด้านที่ต้องการเก็บไว้
5. **คลิก** เพื่อใช้งาน

```
  ก่อน:                     หลัง fillet (รัศมี r):

  ──────────────              ──────────╮
                │                        ╰────
                │
```

## การเลือกด้านสำหรับวัตถุที่ตัดกัน

เมื่อสองวัตถุตัดกัน fillet ถูกใช้กับมุมที่กำหนดโดยตำแหน่งคลิก — ส่วนของแต่ละวัตถุ **ด้านเดียวกับเคอร์เซอร์** จะถูกเก็บไว้

- คลิกใกล้ปลายด้านหนึ่งของวัตถุแรกเพื่อเลือกครึ่งนั้น
- ย้ายเคอร์เซอร์ไปยังครึ่งที่ต้องการของวัตถุที่สอง — ตัวอย่างประอัปเดตสด

## สิ่งที่คำสั่งสร้าง

ผลลัพธ์ขึ้นอยู่กับสิ่งที่คุณเลือก:

- **วัตถุ Line/Arc อิสระสองชิ้น** หรือคู่ใดก็ได้ที่ไม่มี polyline ที่เปิดอยู่: ทั้งสองถูกตัดกลับไปยังจุดสัมผัส **T1**/**T2** และวัตถุ Arc ใหม่ถูกแทรกระหว่างกัน
- **สองส่วนของ polyline เดียวกันที่ใช้จุดยอดมุมร่วมกัน**: ไม่มีวัตถุใหม่ — fillet กลายเป็นส่วนหนึ่งของ polyline เอง จุดยอดมุมถูกแทนที่ด้วยจุดสัมผัสสองจุด และส่วนโค้งระหว่างกันถูกเก็บเป็นค่า bulge ของขอบนั้น — เหมือนกับที่มุม polyline ที่โค้งมนไปกลับผ่าน DXF ทุกประการ
- **ทุกกรณีอื่นที่เกี่ยวข้องกับ polyline ที่เปิด** — polyline ที่เปิดสองอันที่ต่างกัน หรือ polyline ที่เปิดกับ Line/Arc อิสระ: ทั้งสองถูกรวมเป็น **polyline ใหม่หนึ่งเดียว** โดยแต่ละด้านถูกเก็บไว้จนถึงจุดสัมผัสของตน และเชื่อมด้วยส่วนโค้ง fillet เป็นส่วน bulge เพิ่มเติม แทนที่วัตถุเดิม

ส่วนโค้งที่แทรกหรือขยายรับค่าความหนาเส้น สี เลเยอร์ และประเภทเส้นปัจจุบัน (หรือของ polyline เองเมื่อรวมเข้าไปในนั้น)

## มุมที่ไม่มีมุมจริงให้ทำโค้ง

หากสองส่วนที่เลือกมาบรรจบกันแบบสัมผัสอยู่แล้วที่จุดยอดร่วม — มุม polyline ที่ตรง หรือเส้นที่เปลี่ยนอย่างราบรื่นเข้าสู่ส่วนโค้งต่อเนื่องแบบสัมผัส — จะไม่มีมุมจริงที่วงกลมสามารถทำโค้งได้ Fillet ตรวจพบสิ่งนี้และปฏิเสธด้วยข้อความ `cannot fillet: no tangent circle fits there` แทนที่จะวาดวงที่ไม่ต้องการ

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|----------|
| `0`–`9`, `.` | เพิ่มตัวเลขเข้าไปในค่ารัศมี |
| `Backspace` | ลบอักขระที่พิมพ์ล่าสุด |
| `Enter` / `Space` | ยืนยันรัศมีที่พิมพ์และย้ายไปเลือกวัตถุ |
| `Escape` | ยกเลิกและรีเซ็ต |

## วัตถุที่รองรับ

| วัตถุ | รองรับ |
|-------|--------|
| Line | ใช่ |
| Arc | ใช่ |
| Polyline (ส่วนตรงหรือส่วนโค้ง) | ใช่ |
| Circle, Ellipse | ไม่ |
| Text, Spline, Dimension, Leader | ไม่ |

## Fillet vs Chamfer

| | Fillet | Chamfer |
|---|--------|---------|
| ประเภทมุม | ส่วนโค้งมน | การตัดตรง |
| ป้อน | รัศมีหนึ่งค่า | สองระยะ (d1, d2) |
| วัตถุที่แทรก | Arc | Line |
| วัตถุที่รองรับ | Lines, Arcs และ Polylines (ส่วนตรงหรือส่วนโค้ง) | Lines และ Polylines (ส่วนตรงเท่านั้น) |
