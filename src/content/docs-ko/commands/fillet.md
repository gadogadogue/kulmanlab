# Fillet

`fillet` 명령어는 주어진 반지름의 접선 호를 삽입하고 선택한 객체를 그 점까지 잘라내거나(또는 병합하여), 두 [Line](../line/), [Arc](../arc/), [Polyline](../polyline/) 세그먼트 사이의 모서리를 라운딩합니다.

모깎기는 **Line, Arc, Polyline** 객체에서 작동합니다 — 폴리선 자체의 직선 또는 호 세그먼트도 포함됩니다.

## 모깎기 사용

1. 터미널에 `fillet`을 입력하거나 **Fillet** 도구 모음 버튼을 클릭합니다.
2. **모깎기 반지름을 입력**하고 **Enter**를 누릅니다.
3. **첫 번째 선, 호, 또는 폴리선 세그먼트를 클릭** — 클릭한 부분이 교차점의 어느 쪽을 유지할지 결정합니다.
4. **두 번째 객체 위에 커서를 올립니다** — 점선 호 미리보기가 결과 모깎기를 보여줍니다. 유지하려는 측면으로 커서를 이동합니다.
5. **클릭**하여 적용합니다.

```
  이전:                     이후 모깎기(반지름 r):

  ──────────────              ──────────╮
                │                        ╰────
                │
```

## 교차하는 객체의 측면 선택

두 객체가 서로 교차할 때, 모깎기는 클릭 위치로 정의된 모서리에 적용됩니다 — 각 객체에서 **커서와 같은 측면**의 부분이 유지됩니다.

- 첫 번째 객체의 한쪽 끝 근처를 클릭하여 그 절반을 선택합니다.
- 두 번째 객체의 원하는 절반으로 커서를 이동합니다 — 점선 미리보기가 실시간으로 업데이트됩니다.

## 명령어가 만드는 것

결과는 선택한 내용에 따라 달라집니다:

- **독립적인 두 Line/Arc 객체**, 또는 열린 폴리선을 포함하지 않는 조합: 두 객체 모두 접선점 **T1**/**T2**까지 잘리고, 그 사이에 새 Arc 객체가 삽입됩니다.
- **모서리 꼭짓점을 공유하는 동일한 폴리선의 두 세그먼트**: 새 객체 없음 — 모깎기가 폴리선 자체의 일부가 됩니다. 모서리 꼭짓점이 두 접선점으로 교체되고, 그 사이의 호는 해당 변의 bulge 값으로 저장됩니다 — 라운딩된 폴리선 모서리가 DXF를 오가는 방식과 정확히 동일합니다.
- **열린 폴리선이 관련된 그 외 모든 경우** — 서로 다른 두 열린 폴리선, 또는 열린 폴리선과 독립적인 Line/Arc: 두 객체 모두 **하나의 새 폴리선**으로 병합되며, 각 측면은 자신의 접선점까지 유지되고 모깎기 호가 추가 bulge 세그먼트로 그것들을 연결하여 원본 객체를 대체합니다.

삽입되거나 연장된 호는 현재 선 가중치, 색상, 레이어, 선종류 설정을 상속합니다(폴리선에 통합되는 경우에는 폴리선 자체의 설정을 상속합니다).

## 라운딩할 실제 각도가 없는 모서리

선택한 두 세그먼트가 이미 공유 꼭짓점에서 접선 방향으로 만나는 경우 — 직선적인 폴리선 모서리, 또는 접선 연속 호 세그먼트로 매끄럽게 이어지는 선 — 원이 라운딩할 수 있는 실제 모서리가 없습니다. Fillet은 이를 감지하고 원치 않는 루프를 그리는 대신 `cannot fillet: no tangent circle fits there` 메시지로 거부합니다.

## 키보드 참고

| 키 | 동작 |
|----|------|
| `0`–`9`, `.` | 반지름 값에 숫자 추가 |
| `Backspace` | 마지막으로 입력한 문자 삭제 |
| `Enter` / `Space` | 입력한 반지름을 확인하고 객체 선택으로 이동 |
| `Escape` | 취소하고 초기화 |

## 지원되는 객체

| 객체 | 지원 여부 |
|------|----------|
| Line | 예 |
| Arc | 예 |
| Polyline(직선 또는 호 세그먼트) | 예 |
| Circle, Ellipse | 아니오 |
| Text, Spline, Dimension, Leader | 아니오 |

## Fillet vs Chamfer

| | Fillet | Chamfer |
|--|--------|--------|
| 모서리 유형 | 라운딩 호 | 직선 절단 |
| 입력 | 반지름 하나 | 두 거리(d1, d2) |
| 삽입되는 객체 | 호 | 선 |
| 지원 객체 | Line, Arc, Polyline(직선 또는 호 세그먼트) | Line 및 Polyline(직선 세그먼트만 해당) |
