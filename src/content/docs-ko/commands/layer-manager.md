# LayerManager

`LayerManager` 명령어는 도면의 모든 레이어를 나열하는 표를 엽니다. **Freeze**(동결), **Lock**(잠금), **Plot**(플롯), **색상**, **선 가중치**, **선종류**를 행에서 직접 편집할 수 있습니다. 새 레이어를 추가하고 기존 레이어의 동작을 조정하는 중심 위치입니다 — 다른 레이어 명령어([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/))는 각각 이를 열지 않고 하나의 집중된 작업을 수행합니다.

## Layer Manager 열기

- 터미널에 `LayerManager`를 입력하거나, **또는**
- 레이어 패널의 **Layer Manager** 버튼을 클릭합니다.

대화 상자는 떠 있는 패널로 열립니다. 미리 아무것도 선택할 필요가 없습니다.

## 레이어 표

| 열 | 제어하는 것 |
|----|--------------|
| Name | 레이어 이름, 표에서 읽기 전용으로 표시됨(생성 시 한 번 설정) |
| Freeze | 레이어의 객체를 숨기고 동결이 해제될 때까지 선택에서 제외합니다 |
| Lock | 레이어의 객체를 숨기지 않고 편집을 방지합니다 |
| Plot | 인쇄 또는 PDF 내보내기 시 레이어의 객체를 포함할지 여부 |
| Color | 레이어의 ACI 색상 — 견본을 클릭하여 색상 선택기를 엽니다 |
| Lineweight | 레이어의 선 가중치 — 칩을 클릭하여 선 가중치 선택기를 엽니다 |
| Linetype | 레이어의 파선 패턴 — 칩을 클릭하여 선종류 선택기를 엽니다 |

Freeze, Lock, Plot을 전환하면 즉시 적용됩니다 — 별도의 저장 단계가 없습니다. 색상, 선 가중치, 선종류가 **ByLayer**(기본값)로 설정된 객체는 여기서 설정한 값을 따릅니다. 자체 명시적 재정의가 있는 객체는 영향을 받지 않습니다.

## 레이어 추가

1. 표 하단의 **+ Add Layer**를 클릭합니다.
2. 이름을 입력하고 **Enter**를 눌러 확인하거나 **Escape**를 눌러 취소합니다.

레이어 이름에는 문자, 숫자, 공백, `_`, `-`, `$`를 사용할 수 있습니다. 비어 있거나 이미 사용 중이거나 다른 문자를 포함한 이름은 인라인 오류와 함께 거부되며, 행은 다시 시도할 수 있도록 열린 상태로 유지됩니다.

새 레이어는 **동결 해제, 잠금 해제, 플롯 가능** 상태로 시작하며, 색상은 7(흰색/검정), 선 가중치는 Default, 선종류는 Continuous입니다 — [Import](../import/)가 빈 도면의 레이어 `0`에 지정하는 것과 동일한 기본값입니다.

## 여기서 할 수 없는 것

삭제 버튼은 없습니다 — 레이어는 생성된 후 절대 제거되지 않으며, 동결하거나 사용하지 않은 채로 둘 수만 있습니다. 표는 또한 어떤 레이어가 *현재* 레이어인지 표시하지 않습니다. 이는 레이어 패널의 드롭다운이나 [LayerMakeCurrent](../layer-make-current/)를 통해 설정되며, 이 대화 상자에서는 설정되지 않습니다.

## 키보드 참고

| 키 | 동작 |
|----|------|
| `Enter` | 새 레이어의 이름 확인(추가하는 동안) |
| `Escape` | 레이어 추가 취소, 또는 대화 상자 닫기 |

## 관련 명령어

| 명령어 | 기능 |
|--------|------|
| [LayerMakeCurrent](../layer-make-current/) | 클릭한 객체의 레이어를 현재 레이어로 설정 |
| [LayerMatch](../layer-match/) | 선택한 객체의 레이어를 원본 객체의 레이어에 맞게 재지정 |
| [LayerIsolate](../layer-isolate/) | 선택한 객체의 레이어를 제외한 모든 레이어 동결 |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | 한 번에 모든 레이어 동결 해제 |
