# Hatch Manager

`HatchManager` 명령은 실시간 스와치 미리보기와 함께 hatch 패턴을 찾아보고, [Hatch](../hatch/)와 함께 사용할 자체 `.pat` 패턴 파일을 업로드하는 대화 상자를 엽니다.

## Hatch Manager 열기

터미널에 `HatchManager`를 입력하세요. 이는 hatch의 **Pattern** 칩을 클릭할 때 열리는 패턴 선택기와는 별개입니다 — 선택기는 하나의 hatch에 대한 패턴을 선택하고, Hatch Manager는 `.pat` 파일을 추가하거나 제거하는 곳입니다.

## 패턴 그룹

| 그룹 | 내용 |
|------|------|
| **User** | 자체 업로드한 `.pat` 파일의 패턴으로, 각 패턴이 어느 파일에서 왔는지에 따라 하위 그룹화됩니다(하나를 업로드한 후에만 표시됨) |
| **Standard** | `SOLID`와 이 도면 자체의 패턴 테이블 — 모든 새 도면은 레이어와 선종류가 그렇듯 동일한 내장 라이브러리로 시작합니다 |

목록의 패턴을 클릭(또는 `↑`/`↓` 사용)하면 오른쪽에서 미리 볼 수 있습니다 — 캔버스를 채우는 데 사용되는 것과 동일한 코드로 그려진 스와치이므로 도면이 표시할 내용과 정확히 같으며, 패턴의 이름, 설명, 선 개수도 함께 표시됩니다.

## 사용자 지정 패턴 파일 업로드

1. 대화 상자 하단의 **Add .pat File**을 클릭하세요.
2. `.pat` 파일을 선택하세요 — 표준 hatch 패턴 형식입니다. 단일 파일이 한 번에 여러 개의 이름 있는 패턴을 정의하는 경우가 많으며, 모두 해당 파일의 이름 아래에 그룹화된 별도 항목으로 표시됩니다.
3. 업로드된 파일은 브라우저(IndexedDB)에 영구적으로 저장되며, 가장 최근에 추가된 순서로 정렬되고, 다음에 KulmanLab CAD를 열 때 자동으로 다시 로드됩니다.

내장 패턴과 같은 이름의 패턴을 정의하는 파일을 업로드하면 기본값을 **덮어씁니다** — 이는 Autodesk의 공식 패턴 정의를 얻는 지원되는 방법입니다: 실제 `acad.pat`를 업로드하면 ANSI31 및 다른 표준 이름의 해당 버전이 KulmanLab 자체 근사값을 대체합니다.

도면이 라이브러리에 없는 패턴 이름을 참조하는 경우 — 업로드하지 않은 `acad.pat`의 패턴을 사용한 DXF에서 가져온 경우 — hatch는 평평하고 패턴이 없는 채우기로 돌아가는 대신 `ANSI31`을 대체물로 사용하여 계속 렌더링됩니다.

## 패턴 파일 제거

**User** 그룹의 파일 이름 옆에 있는 **×**를 클릭하면 해당 파일과 그것이 정의한 모든 패턴이 제거됩니다. 이미 해당 패턴 중 하나를 사용하는 모든 hatch는 즉시 `ANSI31`로 대체됩니다. 내장 **Standard** 패턴은 제거할 수 없습니다.

## 키보드 참조

| 키 | 동작 |
|----|------|
| `↑` / `↓` | 패턴 목록에서 선택을 위아래로 이동 |
| `Escape` | Hatch Manager 닫기 |
