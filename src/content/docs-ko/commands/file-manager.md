# File Manager

`FileManager` 명령어는 브라우저의 로컬 저장소에 저장된 모든 도면의 **썸네일 그리드**를 엽니다. 각 도면은 마지막으로 저장된 시간순으로 정렬됩니다. 이전 도면을 다시 열거나, 이름을 변경하거나, 삭제하는 데 사용합니다.

## File Manager 여는 방법

- 터미널에 `FileManager`를 입력하거나,
- 화면 상단 파일 패널의 **File Manager** 도구 모음 버튼(기록 아이콘)을 클릭합니다.

패널은 캔버스 왼쪽에 열리며, 다른 명령어를 시작하는 즉시 자동으로 닫힙니다.

## 썸네일 그리드

저장된 각 도면은 실시간으로 렌더링된 썸네일, 이름, 마지막 업데이트 시간을 보여주는 카드로 표시됩니다. 썸네일은 패널을 열 때마다 그 자리에서 생성됩니다 — 미리 렌더링되거나 저장되어 있는 것이 아닙니다 — 따라서 썸네일이 그려지는 동안 카드에 잠시 자리 표시자 아이콘이 나타납니다. 생성에 실패하거나 도면에 실제로 아직 객체가 없는 경우에도 동일한 자리 표시자가 표시됩니다.

| 동작 | 방법 |
|------|------|
| 도면 **열기** | 썸네일 클릭 — 현재 캔버스 내용을 대체합니다 |
| **이름 변경** | 연필 아이콘 클릭 또는 이름 더블클릭 |
| **삭제** | 휴지통 아이콘 클릭 후 확인 |

아직 저장된 파일이 없으면 패널에 "저장된 파일 없음"이 표시됩니다. 한 화면에 다 표시되지 않을 만큼 파일이 많으면 그리드 아래에 **페이지 1/N** 컨트롤이 나타납니다.

## 파일 삭제

휴지통 아이콘을 클릭해도 즉시 삭제되지는 않습니다 — 삭제는 영구적이며 되돌릴 수 없으므로 해당 카드에 확인 오버레이("이 파일을 삭제할까요?"와 **삭제** / **취소** 버튼)가 표시됩니다. **취소**를 클릭하거나, 다른 카드의 휴지통 아이콘을 클릭하거나, 카드의 다른 곳을 클릭하면 아무것도 삭제하지 않고 대기 중이던 확인이 취소됩니다.

## 파일 이름 변경

연필 아이콘을 클릭하거나(또는 파일 이름을 더블클릭하여) 이름을 바로 편집한 다음 **Enter**를 눌러 확인하거나 **Escape**를 눌러 취소합니다. 새 이름이 다음에 해당하면 이름 변경이 거부됩니다:

- 비어 있거나 100자를 초과하는 경우,
- 다른 저장된 파일에서 이미 사용 중인 경우(대소문자 구분 없음),
- 마침표로 끝나는 경우, 또는
- `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`와 같은 Windows 예약 장치 이름인 경우.

파일 이름에 사용할 수 없는 문자(`\ / : * ? " < > |`)는 입력하는 즉시 자동으로 제거됩니다. 이름 변경은 라벨만 바꿀 뿐입니다 — 그리드 내 위치는 이름이 아니라 마지막 저장 시간을 기준으로 정렬되므로 영향을 받지 않습니다.

## 작업 백업 — 브라우저 저장소는 영구적이지 않습니다

KulmanLab은 도면을 브라우저에 내장된 데이터베이스인 **IndexedDB**에 저장합니다:

- 파일은 **오직 사용자의 기기에 로컬로만** 저장됩니다 — 서버에 업로드되지 않습니다.
- 각 브라우저와 기기는 독립적인 저장소를 가집니다. 한 컴퓨터의 Chrome에 저장된 도면은 Firefox에서나 다른 기기에서 나타나지 않습니다.
- 이 저장소는 **경고 없이 지워질 수 있습니다** — 사이트 데이터나 브라우징 기록을 지우거나, 디스크 공간이 부족해지거나, 비공개/시크릿 창을 사용하거나, 브라우저나 OS를 재설치하거나, 기기를 바꾸는 경우 등입니다. 이런 경우 어느 것도 복구할 기회를 주지 않습니다.

**도면을 안전하게 보관하는 유일하게 확실한 방법은 [내보내기](../export/)하여 사용자 자신의 저장소로 옮기는 것입니다.** 가능하면 모든 객체를 정확히 보존하는 KulmanLab의 기본 형식인 `.json`을 사용하고, 다른 CAD 도구와의 호환성이 필요할 때는 `.dxf`를 사용하세요. 잃으면 곤란한 모든 것에 대해, 그리고 브라우저 데이터를 지우거나 브라우저·기기를 바꾸거나 기기를 한동안 사용하지 않고 두기 전에 이렇게 하세요.

## 시작 시 자동 파일 로드

KulmanLab CAD를 열면 앱이 저장소에서 **가장 최근에 수정된 파일**을 자동으로 로드합니다. 매번 File Manager에서 수동으로 열 필요가 없습니다.

## 저장소 관리

저장할 수 있는 도면 수에는 고정된 제한이 없지만 브라우저 저장소는 유한합니다. 저장소 경고가 표시되면 File Manager에서 오래된 파일을 삭제하세요 — 또는 그보다 먼저 내보내어 아무것도 잃지 않도록 하는 것이 더 좋습니다.

한 번에 저장된 모든 도면을 제거하려면 [WipeStorage](../wipestorage/) 명령어를 사용하세요.

## 파일 이름

새 파일과 가져온 파일은 타임스탬프가 포함되지 않은 단순한 이름을 갖습니다. 그 이름이 이미 사용 중이면 Finder/탐색기 스타일의 접미사가 자동으로 붙습니다(`plan (2)`, `plan (3)`, …). 이렇게 하면 아무것도 덮어쓰이지 않습니다. 나중에 [이름 변경](#renaming-a-file)을 사용해 언제든 더 명확한 이름을 지정할 수 있습니다.
