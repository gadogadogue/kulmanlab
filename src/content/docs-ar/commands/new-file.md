# New File

يمسح أمر **New File** اللوحة ويبدأ رسماً فارغاً جديداً. يُنشأ اسم ملف فريد بطابع زمني تلقائياً.

## كيفية إنشاء ملف جديد

انقر على زر **New File** في شريط الأدوات (أيقونة صفحة جديدة) في لوحة الملف. تُمسح اللوحة فوراً — لا توجد موجهات أو مربعات حوار تأكيد.

## ما يحتويه الملف الجديد

يبدأ الملف المُنشأ حديثاً بما يلي:

- **لا عناصر** على اللوحة.
- **طبقة افتراضية واحدة** باسم `0` بلون أبيض ونوع خط `Continuous`.
- **اسم ملف مُنشأ**، `kulman.dxf` — أو `kulman (2).dxf`, `kulman (3).dxf`, … إذا كان هذا الاسم مستخدَماً بالفعل.

يُحفظ الملف في تخزين المتصفح تلقائياً ويظهر في [FileManager](../file-manager/)، ويمكن [إعادة تسميته](../file-manager/#إعادة-تسمية-ملف) في أي وقت.

## تحذير — تُفقد الأعمال غير المحفوظة

النقر على **New File** يتجاهل جميع العناصر الموجودة على اللوحة الحالية دون تحذير. إذا أردت الاحتفاظ بالرسم الحالي، [صدِّره](../export-manager/) أولاً.

## متى تستخدم New File مقابل Import

| الحالة | الإجراء الموصى به |
|--------|-----------------|
| بدء رسم من الصفر | **New File** |
| فتح ملف DXF أو JSON موجود | [Import](../import/) |
| نسخ رسم للعمل على نسخة بديلة | [صدِّر](../export-manager/) الملف الحالي، ثم [استورد](../import/) النسخة |

## الأوامر ذات الصلة

- [Import](../import/) — فتح رسم DXF أو JSON موجود
- [Export Manager](../export-manager/) — تنزيل الرسم قبل البدء من جديد
- [FileManager](../file-manager/) — استعادة رسم سابق من تخزين المتصفح
